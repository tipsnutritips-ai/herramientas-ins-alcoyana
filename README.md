# Herramientas INS Alcoyana

Aplicación web estática preparada para publicar con GitHub + Netlify.

## Publicación

- Repositorio: subir todo el contenido de esta carpeta a la raíz del repositorio.
- Netlify: conectar el repositorio y usar como directorio de publicación la raíz (`.`).
- No requiere build command.

## Estructura

- `index.html` — aplicación
- `supabase-config.js` — configuración de Supabase
- `convenio-index.js` — índice local del buscador del convenio
- `convenios/` — PDFs del convenio
